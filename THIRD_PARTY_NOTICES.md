# Composants tiers

La licence MIT du projet couvre son code original. Elle ne remplace pas les licences de ses dépendances.

Le programme utilise notamment PySide6/Qt, pynput, NumPy, OpenCV, mss, discord.py et aiohttp. La compilation utilise Python, PyInstaller, Pillow et Inno Setup. Consultez les licences exactes des versions installées avant redistribution.

`tools/build_windows.py` recueille les notices des bibliothèques dans un dossier `Licences` inclus dans le programme et le ZIP portable. Les DLL Qt restent séparées. Les textes Qt se trouvent dans `packaging/licences`. Conservez ces notices dans vos distributions et respectez les conditions applicables à chaque composant.

Les services Discord, GitHub et les applications ciblées ne sont pas affiliés à ce projet.
